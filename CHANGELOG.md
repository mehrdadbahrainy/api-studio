# Changelog

Installer files and SHA-256 checksums remain on [GitHub Releases](https://github.com/mehrdadbahrainy/api-studio/releases). Unreleased fixes below do not modify previously published installers.

## [v0.2.2](https://github.com/mehrdadbahrainy/api-studio/releases/tag/v0.2.2) — 2026-11-20

- Reject oversized saved/imported fields and row lists before persistence instead of silently truncating them during reload. Preserve the previous saved workspace and unsaved edits when validation fails.
- Validate browser, DPAPI and passphrase-encrypted writes, malformed request lists and environment identities; add boundary, browser and installed-MSI regressions for [P1 issue #22](https://github.com/mehrdadbahrainy/api-studio/issues/22).
- Keep unreadable browser data protected until explicitly confirmed backup restore; contain dialog focus and block background request shortcuts while modals are active ([issue #24](https://github.com/mehrdadbahrainy/api-studio/issues/24)).
- See [the local QA finding and compatibility limits](docs/qa/v0.2.1-field-integrity.md). The previously published v0.2.1 tag and assets remain unchanged. This correction ships in a new v0.2.2 installer only after all CI release gates pass.

## [v0.2.1](https://github.com/mehrdadbahrainy/api-studio/releases/tag/v0.2.1) — 2026-11-20

Patch release of the local Windows QA corrections. The previously published v0.2.0 installer remains unchanged.

- **Workspace integrity:** reject over-capacity and duplicate-ID backups rather than silently discarding Collections/environments or allowing ambiguous request identities. Keep saved-request capacity separate from History.
- **HTTP timing:** elapsed duration now includes response-body download, not just response headers.
- **Large response diagnostics:** clearly explain the 5 MB transport limit rather than suggesting an unavailable binary download.
- **Accurate History:** record the original sent request snapshot even if URL or headers are edited while a request is running.
- **Regression quality:** extended local HTTP, Postman, editor, backup-restore and Windows installed MSI/WebView2 acceptance; details and known gaps are recorded in [QA #20](https://github.com/mehrdadbahrainy/api-studio/issues/20) and [the Windows QA matrix](docs/qa/windows-v0.2.0.md).
- **Compatibility:** no new data schema, cloud account, or external telemetry. Keep private JSON backups before updating and do not share them publicly.
- Actual native OS file pickers, migration from a vault generated by the v0.1.2 binary, and exhaustive DPI/accessibility audit remain separately tracked; green CI is not a guarantee for every Windows configuration.

## [v0.2.0](https://github.com/mehrdadbahrainy/api-studio/releases/tag/v0.2.0) — 2026-11-19

- Multi-request tabs with per-tab draft/response state, save-discard-cancel on close and saved-tab restoration after restart.
- Nested Collection folders, moving Collections and moving saved requests between Collections without deleting existing requests.
- Raw/Formatted response inspection for JSON, XML and HTML, safe text-only markup, bounded preview, Copy and Save Response.
- Help/About with links to source, README, Persian guide, changelog, issue tracker and license.
- Safe desktop startup/manual GitHub stable-release checks and an update-available notice with the official download link, no silent installation.
- Native browser opening for allowlisted official project URLs.
- Preserve Postman JSON import and DPAPI encrypted Windows storage, with updated unit, browser and installed Windows MSI acceptance.

## [v0.1.4](https://github.com/mehrdadbahrainy/api-studio/releases/tag/v0.1.4) — 2026-11-17

- Expand and collapse individual Collections or all at once, including imported Collections; preserve their layout preferences after restart.
- Resize the sidebar with the splitter (228–480 px) or keyboard; collapse to a compact 68 px rail and reopen it.
- Improve Lucide icon alignment, action-button geometry, navigation spacing and responsive behavior.
- Keep Postman import, secure desktop storage and existing request workflows unchanged.
- Verified [full Windows/Chromium CI](https://github.com/mehrdadbahrainy/api-studio/actions/runs/44063915754) and [successful publication](https://github.com/mehrdadbahrainy/api-studio/actions/runs/44065235512).

## [v0.1.3](https://github.com/mehrdadbahrainy/api-studio/releases/tag/v0.1.3) — 2026-11-17

- Add Postman Collection v2.0/v2.1 and Environment JSON import without removing existing workspace collections.
- Start fresh Windows desktop installs without mandatory app passphrase, using Windows CurrentUser DPAPI.
- Offer an optional application passphrase and migration path for existing v0.1.2 password-protected vaults.
- Add parser, browser and Windows installed MSI regression tests.

## [v0.1.2](https://github.com/mehrdadbahrainy/api-studio/releases/tag/v0.1.2) — 2026-11-16
